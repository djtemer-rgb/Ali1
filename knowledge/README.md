# Ali Quest (Путь героя) — База Знаний и Руководство по Проекту

Добро пожаловать в единую базу знаний проекта **Ali Quest (Путь героя)**.
Этот раздел создан для того, чтобы любой новый разработчик или ИИ-агент мог мгновенно и исчерпывающе понять архитектуру, структуру данных, бэкенд, фронтенд, админ-панель родителей, тестовый режим и все тонкости работы системы.

---

## 🧭 Навигация по Базе Знаний

1. [**Архитектура и Стек Технологий**](./ARCHITECTURE_AND_STACK.md) — обзор стека (Next.js, TypeScript, Tailwind, Redis, Vercel, PWA), структура папок, жизненный цикл запросов.
2. [**Слои Данных и Схема Redis**](./DATA_LAYERS_AND_REDIS.md) — строгое разделение профилей Али и Саида, форматы JSON-документов, ключи Upstash Redis.
3. [**Справочник API (Бэкенд)**](./BACKEND_API_REFERENCE.md) — полное описание всех серверных эндпоинтов `/api/*`, обработка ошибок, `keepalive` и кэширование.
4. [**Фронтенд и Компоненты**](./FRONTEND_COMPONENTS.md) — структура клиентской части, хуки, контекст ребёнка (`ChildContext`), анимации Framer Motion, 5 Canvas-игр.
5. [**Родительская Зона и Админ-Панель**](./PARENT_ADMIN_PANEL.md) — PIN-авторизация (bcrypt + JWT cookie), настройки задач, оценок, наград, ручное управление жизнями (сердечками).
6. [**Режим Тестирования (QA & Demo Mode)**](./TEST_MODE_AND_QA.md) — безопасный просмотр карточек, бонусных игр и мотивационных наград без изменения боевых данных детей.
7. [**Система Мотивационных Наград (Motivational Rewards)**](./MOTIVATIONAL_REWARDS.md) — бесшовные видео-лупы 1:1 (720x720 WebM VP9), аудио ElevenLabs, алгоритм shuffle-bag, модальное окно наград.

## ⚡ Краткая Сводка Проекта

| Параметр | Значение |
| :--- | :--- |
| **Назначение** | Приватный семейный дашборд для двух братьев — Али и Саида |
| **Главная цель** | Короткий ежедневный ритуал выполнения реальных дел (спорт, уроки, порядок, бокс, шахматы), получение оценок, накопление звёзд и наград |
| **Фронтенд** | Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons, Canvas Confetti |
| **Бэкенд** | Next.js Route Handlers (Serverless/Edge), Node.js, REST API |
| **База Данных** | Upstash Redis (REST API), TTL 90 дней |
| **Хостинг** | Vercel (Production URL: `ali1-one.vercel.app`), GitHub Repo: `djtemer-rgb/Ali1` |
| **Безопасность** | PIN-код родителей (двойной слот + Recovery-слово), JWT httpOnly Cookie, изоляция секретов |
| **PWA & Офлайн** | Service Worker (`public/sw.js`), Web Manifest (`public/manifest.json`), кэширование медиа-ассетов |
| **Уведомления** | Telegram Bot API + Web Push Notifications (VAPID) |

## 🚀 Быстрый Старт для Разработчика

```bash
# 1. Клонирование и установка зависимостей
git clone https://github.com/djtemer-rgb/Ali1.git
cd Ali1
npm install

# 2. Запуск в режиме разработки
rm -rf .next
npm run dev

# 3. Сборка для проверки типов и корректности
npm run build
```

> [!IMPORTANT]
> **Правило сборки**: Перед запуском `npm run build` всегда останавливайте dev-сервер и очищайте папку `.next`, чтобы избежать конфликтов сборки Webpack.
