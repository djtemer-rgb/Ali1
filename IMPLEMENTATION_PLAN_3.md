### Критические уроки (чего НЕ делать)

- **НЕ делать много мелких правок.** Каждая правка ломает что-то соседнее. Всё за один проход, потом одна сборка, потом тест.
- **НЕ запускать сервер через `Start-Process`.** На Windows это глючит. Использовать `npx next start` напрямую в bash с таймаутом, либо `Start-Job` (PowerShell background job).
- **НЕ удалять `.next` при каждой сборке.** Инкрементальная сборка быстрее и стабильнее. Полный `Remove-Item .next` — только если явный баг с кэшем.
- **НЕ использовать `html2canvas` для PDF.** Он делает скриншот мобильной версии — результат ужасный. Использовать `@react-pdf/renderer` с регистрацией шрифта, поддерживающего кириллицу.
- **НЕ вставлять скрытые HTML-шаблоны в JSX** для PDF (как я делал с `<div id="report-template" style="display:none">`). Это ломает рендеринг страницы отчётов — краш "Unexpected token '<'".
- **НЕ использовать `alert()` в браузере.** Все уведомления — только через кастомные модалки (уже есть компонент).
- **НЕ предполагать что изменения подхватились.** Пользователь использует `npm run dev`, а не `npm run build && npm run start`. Dev-режим кеширует меньше, но требует hard refresh браузера (Ctrl+F5).
- **НЕ забывать про favicon/meta.** В layout.tsx есть скрипт для service worker, он не должен мешать.
- **КАЖДЫЙ API-роут** проверять что он действительно сохраняет/читает данные. Добавить `console.log` ключей если баг с персистентностью.

## Что несколько раз переделывалось и НЕ РАБОТАЛО стабильно

### 🚫 PDF-экспорт

Было 3 версии:
1. **html2canvas + jspdf (скриншот UI)** — мобильная версия, ужасно
2. **@react-pdf/renderer** — красивый A4, но иероглифы вместо кириллицы (нет шрифта)
3. **html2canvas + скрытый HTML-шаблон (вёрстка в JSX)** — краш страницы отчётов "Unexpected token '<'"

**Что нужно:** @react-pdf/renderer с зарегистрированным шрифтом. Самый надёжный путь — скачать TTF (NotoSans) и положить в `/public/fonts/`, регистрировать через `Font.register({ family: 'NotoSans', src: '/fonts/NotoSans-Regular.ttf' })`. Или использовать серверный API `/api/reports/pdf` для генерации на Node.js.

### 🚫 PIN и сброс

DELETE handler очищает Redis. После этого first login (hasNoPins) должен сработать. Если не срабатывает — значит:
- Либо Redis.getJson возвращает что-то не то
- Либо bcrypt.compare падает при пустом хэше
- Либо JWT cookie не устанавливается

**Что нужно:** Всегда иметь dev-fallback: если Redis не отвечает или auth пустой — пускать с PIN 199991.

### 🚫 Задачи исчезают после refresh

POST сохраняет completed=true, GET его не возвращает. Вероятная причина:
- `getJson` парсит JSON некорректно (см. upstash.ts — там `JSON.parse`)
- Или ключ дня перезаписывается при повторной генерации из шаблонов

**Что нужно:** `console.log` полного цикла: GET→POST→GET, смотреть что реально в Redis.

### 🚫 Server process на Windows

`Start-Process -NoNewWindow cmd /c npx next start` — глючит. `Start-Job` работает стабильно.
