# 5. Родительская Зона и Админ-Панель

Родительская зона предназначена для полного контроля над системой без необходимости использовать сложные связки email/пароль.

---

## 🔒 Авторизация и Безопасность

* **Вход по PIN-коду**: 4-6 значный цифровой код. В системе предусмотрено 2 слота для PIN-кодов (например, для папы и мамы) + 1 секретное Recovery-слово для экстренного сброса.
* **Хэширование**: Хранятся только хэши `bcrypt` в ключе `aq:parent:auth`.
* **Сессия**: После успешного ввода PIN создаётся подписанный JWT-токен (`jose`), который помещается в httpOnly cookie `parent-session` на 7 дней.
* **Dev-байпас**: В среде разработки (`NODE_ENV !== 'production'`) доступна кнопка быстрого входа без PIN.

---

## ⚙️ Возможности Панели Настроек (`/settings`)

1. **Управление Задачами (Шаблоны)**:
   * Создание и редактирование повторяющихся задач по дням недели (Пн..Вс) или разовых задач.
   * Назначение звёзд за выполнение (включая дробные звёзды, шаг 0.5).
   * Категории: Учёба, Спорт, Бокс, Шахматы, Чтение, Порядок, Помощь по дому, Отдых.
   * Настройка подзадач и обязательного просмотра деталей.
2. **Управление Наградами**:
   * Каталог наград с выбором иконки/картинки, цены в звёздах и привязки к ребёнку (`ali`, `said`, `both`).
3. **Школьные Оценки**:
   * Настройка предметов и конвертации оценок (например, 5 -> +10 ⭐, 4 -> +5 ⭐).
   * Переключатель отображения оценок для каждого ребёнка (для Саида доступен режим `littleHeroMode`).
4. **Управление Жизнями Серии (Сердечками)**:
   * Ручная корректировка жизней (0, 1 или 2 ❤️) при болезни или уважительной причине пропуска.
   * Настройка периода автовосстановления жизней (`freezeRestoreDays`, по умолчанию 5 дней).
5. **Родительский Inbox и Telegram**:
   * Просмотр ленты всех событий.
   * Подтверждение выдачи наград.
   * Отправка мгновенных оповещений в Telegram.
