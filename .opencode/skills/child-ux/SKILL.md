## Child UX rules
- Interface must be understandable to a 9-year-old without parent explanation.
- Large click/tap targets.
- Mobile, tablet, laptop, desktop responsive.
- Avoid crowded settings on child screens.
- Use short labels and visual hierarchy.
- Confetti only for meaningful events, not every click.
- Overdue tasks can be softly red, never scary or punitive.
-











 Difficult task completion should require opening details first.

## Task UX
Simple task: one click. Complex task: open details, check subtasks, then complete. Difficulty feedback can be a tiny post-completion selector: easy / normal / hard.

## Tone
Warm, respectful, playful but not babyish. Child is not very small; avoid over-childish UI.
