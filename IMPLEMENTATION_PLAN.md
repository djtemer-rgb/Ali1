## ИТЕРАЦИЯ 1: Фундамент данных (Upstash + Data Contract)

**Цель:** Перевести данные из памяти браузера в Upstash Redis, реализовать Data Contract v1.

### Задачи:

1. **Реализовать ключи Redis (Data Contract v1):**
   - `aq:settings` — общие настройки
   - `aq:children` — список детей
   - `aq:child:ali:profile` и `aq:child:said:profile` — профили (отдельные слои!)
   - `aq:day:ali:YYYY-MM-DD` и `aq:day:said:YYYY-MM-DD` — дневные записи
   - `aq:events:parent` — события для родителя
   - `aq:star-ledger:ali` и `aq:star-ledger:said` — история звезд

2. **Создать API роуты:**
   - `GET/POST /api/settings` — настройки
   - `GET/POST /api/children` — профили детей
   - `GET/POST /api/tasks/templates` — шаблоны задач (создание/редактирование/удаление)
   - `GET/POST /api/tasks/day/[date]` — задачи на день (генерация из шаблонов)
   - `GET/POST /api/grades` — оценки
   - `GET/POST /api/rewards` — награды
   - `GET/POST /api/star-ledger` — история звезд
   - `GET/POST /api/events` — события

3. **Seed данные (первичная запись):**
   - Профиль Али (full mode) и Саида (little-hero mode)
   - Предметы: Математика, Русский язык, Чтение, Окружающий мир, Английский язык
   - Награды: 1 час видеоигр, Поход в кино, Новое Лего
   - Примеры задач: Прочитать 10 страниц, Собрать портфель, Тренировка

4. **Переделать компоненты на API:**
   - `app/page.tsx` — брать задачи и звезды из Upstash
   - `app/settings/page.tsx` — сохранять предметы и награды в базу
   - `app/components/TaskCard.tsx` — выполнение сохранять в API

## ИТЕРАЦИЯ 2: Родительский доступ (PIN + Полные настройки)

**Цель:** Безопасный вход по PIN, полные настройки с аккордеонами.

### Задачи:

1. **Система PIN (серверная):**
   - Два слота PIN + recovery word
   - Хэширование через bcrypt (`bcryptjs`)
   - `POST /api/auth/parent/login` — проверка PIN
   - `GET /api/auth/parent/me` — проверка сессии
   - httpOnly cookie с подписью (`AQ_PARENT_SESSION_SECRET`)

2. **Защита роутов:**
   - `middleware.ts` — проверка сессии для `/parent`, `/settings`

3. **Полные настройки (аккордеоны):**
   - **Профили детей:** имя, режим (full/little-hero), аватар
   - **PIN и восстановление:** два PIN-кода и recovery word
   - **Шаблоны задач:** создание/редактирование/удаление
     - Категория, звезды, дни повторения, время, детали, подзадачи
   - **Предметы и оценки:** настройка + маппинг оценка→звезды (5=+5, 4=+2, 3=0, 2=0)
   - **Награды:** создание/редактирование/удаление (40+ иконок цветных, 40+ минималистичных)
   - **Экономика звезд:** настройки начисления

4. **Раздельные слои для Али и Саида:**
   - Каждый профиль имеет ПОЛНЫЙ набор настроек
   - У Саида в little-hero режиме: оценки можно скрыть (чекбокс в настройках)
   - Переключение профиля в настройках меняет видимость компонентов

### Файлы для изменения:
- `app/api/auth/parent/login/route.ts` (доработать под bcrypt)
- `app/api/auth/parent/me/route.ts` (доработать)
- `app/api/auth/parent/settings/route.ts` (новый — сохранение PIN)
- `middleware.ts` (новый)
- `app/parent/page.tsx` (переделать на реальную авторизацию)
- `app/settings/page.tsx` (доработать аккордеоны под полные настройки)

### Env (добавить):
```
AQ_PARENT_SESSION_SECRET=generate-long-random-secret
```

### Чек-лист после реализации:
- [ ] Вход по PIN работает (два слота)
- [ ] Recovery word работает
- [ ] Сессия запоминается в cookie
- [ ] Нельзя зайти в /parent и /settings без PIN
- [ ] Настройки сохраняются в Redis
- [ ] Переключение Али/Саид в настройках работает
- [ ] У Саида можно скрыть оценки
- [ ] `npm run build` проходит без ошибок
