# 1. Архитектура и Стек Технологий

Проект **«Путь героя» (Ali Quest)** спроектирован как высокопроизводительное, приватное семейное веб-приложение, работающее на смартфонах (включая режим PWA на Android/iOS), планшетах и десктопах.

---

## 🛠️ Технологический Стек

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| **Фреймворк** | Next.js 14 (App Router) | Серверный и клиентский рендеринг, API Route Handlers |
| **Язык** | TypeScript | Строгая типизация моделей данных, ответов API и стейта |
| **Стилизация** | Tailwind CSS | Адаптивная вёрстка (mobile-first), темы детей |
| **Анимации** | Framer Motion & Canvas Confetti | Плавные переходы, карточки, конфетти при победе |
| **База Данных** | Upstash Redis REST API | Быстрое key-value хранилище с TTL 90 дней |
| **Безопасность** | `jose` (JWT), `bcryptjs` | Хэширование PIN-кодов, cookie-сессии родителей |
| **PWA & Offline** | Web App Manifest + Service Worker | Установка на домашний экран, кэширование статики и видео |
| **Медиа Обработка** | FFmpeg (WebM VP9 Lanczos), ElevenLabs | 720x720 1:1 видео-лупы, аудио-мотивация |
| **Уведомления** | Telegram Bot API, `web-push` (VAPID) | Оповещения родителя о выполнении задач, списании жизней |

## 🔄 Жизненный Цикл Запросов и Надёжность (`keepalive: true`)

1. **Изоляция секретов**: Переменные среды (`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `TELEGRAM_BOT_TOKEN`, `AQ_PARENT_SESSION_SECRET`) доступны только серверному коду Next.js. Браузер никогда не получает прямых ключей от БД или ботов.
2. **Гарантированное сохранение при закрытии (`keepalive`)**:
   Дети часто закрывают браузер сразу после выполнения задачи. Чтобы запрос не был оборван браузером, все критические запросы отправляются с параметром:
   ```typescript
   fetch('/api/tasks/day', {
     method: 'POST',
     headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify({ ... }),
     keepalive: true // Завершает передачу даже при закрытии страницы
   });
   ```
3. **Чистые функции**: Вся логика подсчёта дней серии и заморозок вынесена в детерминированную чистую функцию `processStreakAndHearts` в `app/lib/streak-utils.ts`.
