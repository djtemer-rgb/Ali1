# Бонусные игры за Серию Дней

Когда ребёнок накапливает определенное количество дней серии (Streak), он открывает новые карточки наград, содержащие доступ к бонусным HTML5 Canvas играм.

---

## Список игр и Персонажи

В зависимости от карточки награды (серии дней) запускается конкретная игра с уникальным скином персонажа, препятствиями и цветовой гаммой:

1. **Забег героя (RunnerGame.tsx)** — классический раннер с прыжками:
   - `streak-reward-1`: Панда Бамбу (Весенняя тема)
   - `streak-reward-5`: Хаски Фрост (Зимняя тема)
   - `streak-reward-7`: Лисёнок Фокси (Летняя тема)
   - `streak-reward-15`: Хамелеон Спектрум (Осенняя тема)
2. **Ловец звёзд (CatcherGame.tsx)** — ловля падающих предметов:
   - `streak-reward-2`: Капибара Капи (Летний речной берег)
   - `streak-reward-14`: Бык Гром (Грозовые равнины)
   - `streak-reward-17`: Носорог Титан (Фиолетовые кристальные пещеры)
3. **Прыжки по звёздам (JumpGame.tsx)** — вертикальный дудл-джамп
4. **Быстрая реакция (TapReactionGame.tsx)** — тапы на скорость по появляющимся целям
5. **Полёт сквозь порталы (FlightGame.tsx)** — полёт дракончиков / орлёнка:
   - `streak-reward-6`: Ледяной дракон Кристалл (Снежная тема)
   - `streak-reward-11`: Огненный дракон Искрик (Огненная тема)
   - `streak-reward-13`: Орлёнок Скай (Небесная тема)
   - `streak-reward-16`: Лесной дракон Вердан (Магический лес)

## Механика Поворота Экрана (Landscape Mode)

Игры Catcher, Runner и **Flight** разработаны для горизонтального (альбомного) формата экрана. Для мобильных устройств предусмотрен автоматический поворот:

1. **Определение ориентации**:
   Хук в эффекте проверяет соотношение высоты и ширины окна:
   ```typescript
   setShouldRotate(window.innerHeight > window.innerWidth);
   ```
2. **Поворот контейнера через CSS**:
   Если `shouldRotate === true` (телефон удерживается вертикально), к обёртке игры применяется CSS-стиль:
   ```css
   width: 100vh;
   height: 100vw;
   transform: rotate(90deg);
   transform-origin: center;
   ```
   Это принудительно разворачивает горизонтальный игровой холст на 90 градусов, адаптируя его под вертикальный экран.
3. **Предупреждение о необходимости переворота**:
   Внутри развернутого контейнера поверх игры на 2.5 секунды отображается оверлей `showRotationHint` с текстом: **«Поверни телефон»** и кнопкой **«Понятно»**, подсказывая пользователю повернуть устройство физически для удобства управления.

## Сохранение результатов

После успешного прохождения игры на сервер отправляется POST-запрос `/api/bonus-games`:
```json
{
  "childId": "said",
  "rewardId": "streak-reward-6",
  "gameId": "flight",
  "completed": true
}
```
Это блокирует повторное прохождение игры в этот день (кнопка становится «Игра пройдена 🏆»), предотвращая злоупотребления геймификацией.
